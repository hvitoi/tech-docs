# Project Structure

## Flat Structure

- It's the preferred format for `libraries`
- Usually in a flat project structure, the project will have a `go.mod` with the module name with the same name of the repository. And also a `<project>.go` entrypoint file with the same name of the project too that is the main entrypoint of the package
- Examples
  - <https://github.com/golang/term>
  - <https://github.com/spf13/cobra>

# VictoriaMetrics Alert

- Handles `alerting` & `recording rules` (optional)
- Evaluates Prometheus-style alerting and recording rules. It reads from vmselect (or single-node) via the query API, and writes recording-rule results back through vminsert (remote_write). Fires alerts to Alertmanager.
- It's `stateless`; use `-remoteWrite/-remoteRead` so its alert state survives restarts.
